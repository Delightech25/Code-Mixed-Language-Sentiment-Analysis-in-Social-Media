# Code-Mixed-Language-Sentiment-Analysis-in-Social-Media
Code-Mixed Language Sentiment Analysis in social media is the computational task of predicting the sentiment polarity $Y \in \{\text{Positive}, \text{Negative}, \text{Neutral}\}$ of user-generated text containing token-level transitions between two or more language systems ($L_1, L_2$) within a single document, sentence, or phrase.
