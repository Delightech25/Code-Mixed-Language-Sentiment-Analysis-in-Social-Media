=# Code-Mixed Language Sentiment Analysis in Social Media

A computational framework for predicting the sentiment polarity $Y \in \{\text{Positive}, \text{Negative}, \text{Neutral}\}$ of user-generated text containing token-level transitions between two or more language systems ($L_1, L_2$) within a single document, sentence, or phrase.

---

## 📌 Overview

With the rise of multilingual communication on social media platforms (e.g., Twitter/X, Instagram, WhatsApp), users frequently mix two or more languages within the same conversation or sentence (code-mixing/code-switching). Traditional sentiment analysis models often struggle with these token-level language shifts. 

This repository provides code, datasets, and models designed to effectively classify and analyze sentiment in code-mixed social media text.

---

## 🚀 Key Features

* **Token-Level Analysis:** Handles complex linguistic transitions between multiple languages ($L_1, L_2$, etc.).
* **Social Media Focused:** Optimized for noisy, unstructured text featuring slang, abbreviations, and informal code-switching.
* **Multi-Class Sentiment Classification:** Categorizes text into **Positive**, **Negative**, or **Neutral** polarities.
